# Check for an open safety review before any sample

pod.md says a creator with an open safety review gets no new sample until Nora clears it. The agent only looks at
the message in front of it, so when the same creator asks for another product in a later task, it ships.

Before approving any sample request:
1. Check whether we escalated a reaction from this creator to Nora earlier, in any task. Keep a list in the run
   folder as you go, and read the creator's thread.
2. Open review: don't ship. Tell them we'll hold new samples until Nora has checked in with them.

Caught this twice this week, both on Fish Oil requests a day after a reaction report.
